# Community Ruby Plugin for Apache NetBeans

[Community Ruby](https://github.com/piotrhoppe/community-ruby) is a community-maintained plugin for Apache NetBeans that provides a full-featured integrated development environment for building, running, testing and debugging Ruby and Ruby on Rails applications.

## Overview

The plugin adds first-class Ruby support to NetBeans, including syntax highlighting, intelligent code completion, refactoring tools, an integrated debugger, unit testing, Rake support and Rails project management.

## Features

- **Editing**: Syntax highlighting, code completion, hints and quick fixes
- **Refactoring**: Safe rename, extract method and other refactorings
- **Projects**: Ruby and Ruby on Rails project support
- **Debugging**: Integrated debugger with breakpoints and variable inspection
- **Testing**: Unit testing and code coverage support
- **Tools**: Rake runner, Gems manager, live code templates
