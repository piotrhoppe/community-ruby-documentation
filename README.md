# NetBeans Community Ruby Plugin Documentation

[Community Ruby](https://github.com/piotrhoppe/community-ruby) is a plugin for NetBeans that provides an integrated 
development environment for building, running, testing, and debugging Ruby and 
Ruby on Rails applications.
